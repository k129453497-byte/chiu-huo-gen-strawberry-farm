# 邱火根草莓園

此儲存庫為邱火根草莓園的公開靜態網站版本，提供繁體中文、簡體中文與英文內容。網站採用原始農場照片、影片與質譜快檢報告；採果開放狀態與價格請於出發當日以電話或 LINE 確認。

## 公開網站

本儲存庫透過 GitHub Pages 發佈。網站根目錄內含所有執行所需的圖片、影片、樣式與 JavaScript，因此可直接由 GitHub Pages 提供。

## 內容範圍

此公開版本不包含「網頁架構」選單與教學彈出頁。網站的三語切換使用頁首的 CHT、CHS、ENU 按鈕；也可在網址後方加入 `?lang=zh-TW`、`?lang=zh-CN` 或 `?lang=en` 直接開啟指定語系。

## 維護提醒

修改內容後，請確認首頁影片、草莓日常相片、質譜快檢報告、Google 地圖及電話／LINE 連結均正常，再推送至 GitHub Pages。
